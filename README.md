# MediCare Hospital Admission System

## Description
A Java-based hospital admission system .

## Features
- Patient registration
- Patient searching
- Patient updating
- Patient deletion
- Bed management
- Patient reports
- Bed occupancy reports
- Patient sorting
- Validation and exception handling

## Technologies Used
- Java
- NetBeans
- GitHub

## Object-Oriented Programming
The system demonstrates:
- Encapsulation
- Inheritance
- Constructor chaining
- Method overriding
- Exception handling

## Testing
The system includes tests for:
- CRUD operations
- Bed management
- Validation and boundary conditions
